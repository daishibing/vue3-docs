# 模块导入规范

通过 ESLint 配置，统一模块导入规范

# 安装扩展插件

```shell
npm install -D eslint-plugin-import-x

npm install -D eslint-import-resolver-typescript
```

# 规范说明

| 规则                            | 主要作用           | 使用原因                                    |
|---------------------------------|--------------------|---------------------------------------------|
| extensions                      | 检查模块文件扩展名 | 统一省略可省略的模块文件扩展名              |
| no-duplicates                   | 检查重复导入       | 避免从同一个模块多次导入                    |
| no-unresolved                   | 检查模块解析       | 确保导入的模块能够被正确解析                |
| no-useless-path-segments        | 检查无意义路径     | 避免 `.././` 和 `/index` 等冗余路径         |
| no-self-import                  | 检查自身导入       | 避免模块导入自身                            |
| consistent-type-specifier-style | 检查类型导入写法   | 统一使用独立的 `import type`                |
| no-extraneous-dependencies      | 检查依赖声明       | 确保使用的 npm 包已在 `package.json` 中声明 |
| no-cycle                        | 检查循环依赖       | 避免模块之间形成循环依赖                    |
| order                           | 检查导入顺序       | 统一模块导入分组和顺序                      |
| newline-after-import            | 检查导入后的空行   | 统一模块导入与其他代码之间的空行            |

# 配置 `eslint.config.ts`

```ts
import importX from "eslint-plugin-import-x"
import { defineConfigWithVueTs } from "@vue/eslint-config-typescript"

export default defineConfigWithVueTs(
    // 其他配置
    {
        plugins: {
            "import-x": importX,
        },
        settings: {
            "import-x/resolver": {
                typescript: true,
            },
        },
        rules: {
            "import-x/extensions": ["error", "never"],
            "import-x/no-duplicates": "error",
            "import-x/no-unresolved": "error",
            "import-x/no-useless-path-segments": [
                "error",
                {
                    noUselessIndex: true,
                },
            ],
            "import-x/no-self-import": "error",
            "import-x/consistent-type-specifier-style": ["error", "prefer-top-level"],
            "import-x/no-extraneous-dependencies": [
                "error",
                {
                    devDependencies: true,
                    optionalDependencies: false,
                    peerDependencies: true,
                },
            ],
            "import-x/no-cycle": "error",
            "import-x/order": [
                "error",
                {
                    groups: [
                        "builtin",
                        "external",
                        "internal",
                        "parent",
                        "sibling",
                        "index",
                        "type",
                    ],
                    "newlines-between": "always",
                },
            ],
            "import-x/newline-after-import": "error",
        },
    },
)
```
