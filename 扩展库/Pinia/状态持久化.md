# 状态持久化

使用 `pinia-plugin-persistedstate` 为 Pinia Store 提供状态持久化

# 安装扩展插件

```shell
npm install pinia-plugin-persistedstate
```

# 配置扩展插件

`src/stores/index.ts`：

```ts
import { createPinia } from "pinia"
import { createPersistedState } from "pinia-plugin-persistedstate"

const pinia = createPinia()

pinia.use(
    createPersistedState({
        key: (id) => `pinia-${id}`,
    }),
)

export default pinia
```

`src/main.ts`：

```ts
import { createApp } from "vue"

import App from "./App.vue"
import pinia from "./stores"

const app = createApp(App)

app.use(pinia)
app.mount("#app")
```

# 扩展插件基本用法

开启状态持久化后默认存储在 `localStorage`，页面刷新或重新打开网站后仍然存在

默认持久化：

```ts
import { ref } from "vue"
import { defineStore } from "pinia"

export const useCounterStore = defineStore(
    "counter",
    () => {
        const a = ref(0)

        return { a }
    },
    {
        persist: true,
    },
)
```

指定字段持久化：

```ts
import { ref } from "vue"
import { defineStore } from "pinia"

export const useCounterStore = defineStore(
    "counter",
    () => {
        const a = ref(0)
        const b = ref(0)
        const c = ref(0)

        return {
            a,
            b,
            c,
        }
    },
    {
        persist: {
            pick: ["a", "b"],
        },
    },
)
```
